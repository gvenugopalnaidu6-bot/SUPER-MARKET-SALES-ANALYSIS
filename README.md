# 🛒 SUPER-MARKET-SALES-ANALYSIS USING EXCEL, SQL, POWER BI

## 📊 Project Overview
Analyzed 1000+ supermarket transactions to identify top-selling products, profit trends, and customer behavior. This project helps supermarket owners make data-driven decisions.

## 🛠️ Tools & Skills Used
- **Excel:** Data Cleaning, Pivot Table, VLOOKUP, Charts
- **SQL:** Data Cleaning & Filtering
- **Power BI:** Interactive Sales Dashboard & KPI's

## 🔍 Key Insights Found
- 🥤 **Beverages** Category = 35% of Total Sales - Highest Selling!
- 💵 **Cash** = 60% Customers prefer Cash Payment
- 📅 **Weekends** = Sales 40% Higher than Weekdays
- 🏙️ **Naypyitaw City** has the Highest Profit

## 📁 Files in this Repo
- `Sales Data.xlsx` - Cleaned & Raw Dataset
- `SALES DASHBOARD FINAL.pbix` - Power BI Dashboard File
